# ADR 0007：测试分层与运行位置

- 状态：已修订（2026-11-08），随 ADR 0005 生效（0005 已批准）。
- 相关：ADR 0005（其 9 个验收场景是存储层实现的完成条件）、ADR 0006（依赖边界检查）。

## 背景
盘点显示五层测试，运行位置分散；smoke 不在 CI；哨兵测试在沙箱里无法运行（根目录写死在主目录）；真实集成靠 gate 清单开关。

## 决定
| 层 | 默认运行 | 执行会话（沙箱） | 维护者普通终端 | CI |
|---|---|---|---|---|
| 单测（含真实 Git 临时仓库、Fake） | 是 | 是 | 是 | 两平台 |
| **存储场景测试**（ADR 0005 的 9 个验收场景 + 数据目录检测；临时目录，检测接口可注入） | 是 | 是 | 是 | 两平台 |
| **依赖边界检查**（ADR 0006） | 是 | 是 | 是 | 两平台 |
| 哨兵 | 是 | 否（需写主目录）→ 改为可配置根目录，默认系统临时目录，使沙箱也能跑 | 是 | 两平台 |
| Fake e2e | 否 | 否 | 是 | macOS |
| smoke | 否 | 否 | 是 | **新增到 macOS CI** |
| 真实集成 | 否 | 否 | 是（任务文件写明次数并预先授权） | 不跑 |

规则：
- 任务完成的门槛 = 单测 + 构建 + 维护者跑 e2e/smoke（涉及界面或接线时）+ CI 绿。
- 涉及执行体接口变化的任务，必须至少 1 次真实集成。
- **涉及持久化的任务，ADR 0005 的 9 个场景测试必须全部通过**；这 9 个场景是存储层实现完成的条件，在实现前以待实现项（`it.todo`）占位，不允许删除。
- 哨兵改用系统临时目录后，必须保留“对照组”（同样配置交给不受控的 git，哨兵会出现），以证明哨兵布置仍然有效；这条对照已存在，不得删除。

## 后果
执行会话不再因沙箱限制留下“未验证”项；存储与边界规则在每次提交都被检查。
