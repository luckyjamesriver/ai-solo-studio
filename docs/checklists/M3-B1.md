# M3-B1 维护者本机验收清单（入口与环境）

目标：入门用户从 Dock/Finder 打开应用（不经终端），能选中自己的项目文件夹，并看懂“我的电脑能不能开始用、不能的话卡在哪、怎么办”。

准备：Node 22（`node -v` 显示 v22.x）；已执行 `npm install`，并按 README 用 `node node_modules/electron/cli.js --version` 确认 Electron 可用；`npm run build` 已成功。

## A. 从 Finder/Dock 启动（不经终端）
- [ ] 在终端执行一次 `open node_modules/electron/dist/Electron.app --args "$PWD" --user-data-dir=/tmp/studio-b1`（或把它拖进 Dock 后点击）。注意：这样启动的应用拿到的是系统最小 PATH。
- [ ] 窗口出现；“你的电脑准备好了吗”里 Git、Node.js、npm、Codex 四项都能显示结果，**不是一直转圈、也不是空白**。
- [ ] 展开“排查信息（PATH）”：能看到应用看到的 PATH（通常只有 /usr/bin:/bin:/usr/sbin:/sbin）。
- [ ] 如果 Homebrew 装的 node/codex 不在最小 PATH 里，对应项下方显示“通过补全路径找到”，并写出位置；补全的目录列在排查信息里。
- [ ] 终端里 `echo $PATH` 没有被改动（本应用只影响它自己启动的子进程）。

## B. 首次外发告知
- [ ] 第一次启动先弹出“使用前请了解：资料会发给谁”：列出服务名（装了 Codex 时有“OpenAI（Codex）”）、何时发送、不会发送什么。
- [ ] 点“暂不同意，先看看”：能继续浏览体检；“资料外发”一栏写着“尚未确认”；重启后再次询问。
- [ ] 点“我了解了，同意”：弹窗关闭；重启后不再弹出；“资料外发”一栏写着“已确认”，可点“查看外发说明”再次查看。
- [ ] 应用数据目录（`--user-data-dir` 指定的目录）里有 disclosure.json，其中没有任何凭证内容。

## C. 打开项目
- [ ] **普通 Git 项目**：点“打开项目文件夹”，用系统对话框选一个已有 Git 的项目 → 显示项目名与保存点。
- [ ] **非 Git 文件夹**：选一个没有 .git 的文件夹 → 出现说明“将在这个文件夹里创建版本记录（.git），不会修改你的文件”。
  - [ ] 点“不同意，不打开”：没有打开；文件夹里**没有**出现 .git。
  - [ ] 再选一次，点“同意…”：打开成功；文件夹里出现 .git；你原有文件内容没变。
- [ ] **有未提交改动的 Git 项目**：先在项目里改一个文件但不提交 → 打开后出现提示“有 N 个文件的改动还没有保存，后续施工会基于已保存的版本”；用 `git log` 确认应用没有替你提交。
- [ ] **被拒绝的文件夹**：选你的用户主目录、`/usr`、`/Applications` → 都被拒绝并说明原因；选“另一个 Git 项目内部的子文件夹”→ 提示选最外层。
- [ ] **最近项目**：回到首页（点“换一个项目”或重启）能看到刚才的项目与上次打开时间；点它能直接打开；把该文件夹改名后，该条目显示“文件夹已不存在”且不可点。

## D. 体检各种情形
- [ ] **Node 版本不一致**：准备一个 `.nvmrc` 写 `20`（或 engines.node 写 `>=24`）的项目并打开 → Node.js 的“版本兼容”显示“不通过”，写明项目要求与你的版本，下方有“请安装 Node 20…”。
- [ ] `.nvmrc` 写 `lts/*` 的项目 → “版本兼容”显示“未知”（不是通过）。
- [ ] 项目没有 .nvmrc 也没有 engines → 显示“不适用：项目未声明”。
- [ ] **Codex 未登录**（如可模拟）：先 `codex logout`（会改变你的登录状态，完成后请重新登录；或在另一台机器/账号上验证）→ Codex 的“已登录”显示“不通过”，并提示登录。无法模拟则记为“未验证”。
- [ ] Codex 的“版本兼容”：本机版本是已验证版本时通过，其他版本显示“未知（未经验证）”。
- [ ] Codex 的“安全配置已核验”：显示“启动前自检通过（只读检查，没有启动任务）”。
- [ ] 若本机有全局 AGENTS.md 或 skills：“已知的限制”一栏用一句话说明；没有就不显示这一栏。
- [ ] 任何一项不通过，都有一句“怎么办”，且**没有**“一键修复”之类会改你电脑环境的按钮。

## E. 自动化
- [ ] `npm run typecheck`、`npm test`、`npm run build`、`npm run smoke`（Node 22）全部通过。
- [ ] `npm run test:e2e` 在本机通过（需要显示环境）。
