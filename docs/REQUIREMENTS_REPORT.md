说明：现行实现（B3）是标准模式下施工中没有任何审批，权限边界由开工前授予的能力决定，碰到边界的操作会失败并写进验收结果；完全信任模式在每个任务开工前单独确认，项目级偏好只做预选。“在项目层面一次性披露、可对单个项目放开”与这一实现的差别（目前是任务级确认），由后续任务决定是否调整。
