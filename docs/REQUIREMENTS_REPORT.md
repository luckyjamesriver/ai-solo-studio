## 后续版本待办（2026-11-09 调研记录）

### 1. 额度用量面板
- **目的**：入门用户不了解订阅额度，任务做到一半额度用完会造成中断和半成品。
- **内容**：显示当前执行者（先做 Codex）的额度剩余和重置时间；开工前，如果额度明显不足，给出提醒。
- **约束**：数据必须来自官方提供的接口或 CLI 输出，拿不到就显示“无法获取”，不能估算或编造数字（零虚构原则）；实现前先调研 Codex 是否提供额度查询接口。
- **参考来源**：Beluga（github.com/kayraucklnc/beluga，MIT 许可证），2026-11-09 调研。

### 2. 证据面板
- **目的**：让用户看到 Agent 实际做了什么，而不只是它的文字汇报。
- **内容**：任务进行中，实时展示 Agent 产生的截图、测试结果和日志；验收时把这些证据和验收标准放在一起展示。
- **约束**：证据文件存放在任务 worktree 内一个被 Git 忽略的目录中，不进入提交；权威状态仍由统一写入服务管理，证据面板只读展示。
- **参考来源**：Beluga（github.com/kayraucklnc/beluga，MIT 许可证），2026-11-09 调研。
