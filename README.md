# AI Solo Studio (ai-solo-studio)

> **专为独立创作者（Solo Creator）与非 IT 程序员设计的“多 AI 协同虚拟工作室”。**  
> 把复杂冰冷的代码终端留给底层执行体，把宽敞明亮的“战略办公室”留给你和顶尖 AI 智囊团。

## 🌟 核心理念与诞生背景

### 为什么现有工具不适合普通人？
当前的 AI 辅助开发工具（如 AutoGen、CrewAI、Docker 化多 Agent）几乎都是**“程序员做给程序员用的”**——满屏不可读的终端、复杂的 Git 冲突处理、繁琐的 API Token 充值与计费。

而对于一个有创意、有想法的非 IT 门外汉来说，最想要的是：
1. **一个想法就能开工**：用大白话输入 Idea，由 AI 帮你梳理出落地需求和架构方案；
2. **多 AI 协同智囊团（双 PM）**：让 **Claude**（擅长长程规划与架构）和 **ChatGPT**（擅长逻辑推演与风控）在同一个房间里互相讨论、挑刺并完善方案，而不是单模型自言自语；
3. **分层执行（手脑分离）**：讨论成熟后，自动将任务派发给底层的“执行工匠”（如 Cursor、Claude Code CLI、Antigravity、DeepSeek），自动执行、自动测试、自动汇报；
4. **老板特权（双模干预通道）**：
   - 🔴 **紧急暂停（Pause）**：随时随地一键冻结所有进程，插话调整大方向；
   - 🟡 **里程碑请示（Checkpoint）**：每完成一个核心大节点，AI 主动弹出卡片请你检阅并拍板；
5. **自带订阅友好（BYOS）**：优先支持已经购买的 Claude Pro、ChatGPT Plus、Cursor 等本地订阅，无需额外昂贵的 API 计费。

## 🚀 极速起步 (Getting Started)

本工程采用 **Electron + React + Vite + TailwindCSS** 打造，兼具 Web 的开发轻巧度与原生桌面端的系统调用能力。

### 1. 克隆与安装依赖
```bash
git clone https://github.com/luckyjamesriver/ai-solo-studio.git
cd ai-solo-studio

# 安装依赖 (标准 npm，通常不到 30 秒)
npm install
```

### 2. 启动开发模式

* **Web 浏览器极速体验**（适合调试界面）：
  ```bash
  npm run dev:web
  ```
  浏览器打开 `http://localhost:5173` 即可实时体验。

* **桌面应用模式**（体验完整本地桌面与终端调度）：
  ```bash
  npm run dev
  ```
  自动拉起原生桌面客户端窗口。
